Put these four font files in this folder (free from fonts.google.com: open each family, click Get font / Download, unzip):

InstrumentSerif-Regular.ttf
InstrumentSerif-Italic.ttf
DMSans.ttf          (rename the file called DMSans[opsz,wght].ttf)
DMSans-Italic.ttf   (rename the file called DMSans-Italic[opsz,wght].ttf)

Until they are here, the site falls back to Georgia and your device's standard font, and still looks fine.
